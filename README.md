# matan-z

Excel / Access VBA で業務の自動化に12年取り組んできました。業務の自動化による外注費の削減で、社内表彰を受けています。

現在は Claude Code・Codex などの AI コーディングエージェントを使い、Web アプリの開発に取り組んでいます。AI にコードを書かせるだけでなく、**AI の出力をテストや検証の仕組みで確かめ、どこで人が判断するかを設計すること**を大切にしています。

## 公開中のプロジェクト

| プロジェクト | 内容 | 主な技術 |
|---|---|---|
| [見抜け！詐欺メール](https://github.com/matan-z/phish-or-real)<br>[デモ](https://phish-or-real.vercel.app) | メール・SMS を15秒で「本物／フィッシング」と判定し、危険のサインを解説する研修用ゲーム。AI エージェントの作業を自動検証する仕組み（ハーネス）を先に作って開発 | TypeScript, Vite, Vitest, JSON Schema |
| [Web Security Inspector](https://github.com/matan-z/web-security-inspector)<br>[デモ](https://web-security-inspector-sepia.vercel.app) | Web サイトの HTTPS・証明書・セキュリティヘッダー・Cookie の設定を診断し、改善方法を日本語で示す。SSRF 対策や DNS によるドメイン確認など、ツール自体の安全性を重視 | Next.js, React, TypeScript, GitHub OAuth, Playwright |
| [観音経 暗記道場](https://github.com/matan-z/KannonSutra)<br>[デモ](https://kannonsutra.vercel.app) | お経の119句を6種類のミニゲームで覚える学習アプリ。学習用の合成音声を Python と VOICEVOX で生成 | JavaScript, Python, VOICEVOX |
| [KoreDeFilter](https://github.com/matan-z/KoreDeFilter) | 貼り付けたリストで Excel の表をまとめて絞り込むアドイン。VBA をテキストで管理し、PowerShell で自動テスト | Excel VBA, PowerShell |
